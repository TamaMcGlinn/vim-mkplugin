==============================================================================
INTRODUCTION                                                  *mkplugin-intro*

mkplugin uses cookiecutter with a custom vimscript template to quickly create
and then start editing a new plugin.

==============================================================================
PREREQUISITES                                              *mkplugin-prereqs*

Flog supports Vim 8, Vim 9, and Neovim.

==============================================================================
COMMANDS                                                   *mkplugin-commands*

MkPlugin [plugin-name]

    Create a plugin in ~/.vim/plugged/vim-[plugin-name]
==============================================================================
MAPPINGS                                                 *mkplugin-mappings*

    None. We suggest adding this to your vimrc:

    nnoremap <leader>vpn :MkPlugin 

    Note the trailing space. You trigger it and then type the name for the
    plugin and let mkplugin drop you into the autoload/*.vim file.

==============================================================================
FUNCTIONS                                                *mkplugin-functions*

mkplugin#mk(plugin_name)
